Apple Silicon / macOS

Classless ships an unsigned shell launcher, ClasslessLauncherMacos.zip, that syncs the shared game folder from Garage and hands off to WoWSilicon. It never runs wow.exe natively.

Install ClasslessLauncherMacos

  1. Download via the button below (or GET /files/downloadlauncher/macos).
  2. Create a game folder, e.g. ~/Games/ClasslessWoW, and unzip ClasslessLauncherMacos.zip into it (Archive Utility is fine — real zip).
  3. Clear Gatekeeper quarantine (no Apple Developer ID / notarization): 
    xattr -dr com.apple.quarantine ~/Games/ClasslessWoW/ClasslessLauncherMacos.app
  4. Install p7zip once (needed to extract GameClient.7z on first run): 
    brew install p7zip
  5. Open ClasslessLauncherMacos.app. First run may download the client (~17 GB), sync patch-n.mpq, and install a Turoran mirror of WoWSilicon into ~/Applications if missing.

WoWSilicon profile

  • Project: github.com/WoWSilicon/WoWSilicon
  • Site / upstream downloads: wowsilicon.github.io
  • Requirements: Apple Silicon Mac (M1+), macOS 15+
  • In WoWSilicon, create/select a WrathSilicon (3.3.5a) or Custom profile and point it at your Classless game folder, then Patch once.
  • If Gatekeeper blocks WoWSilicon: 
    xattr -dr com.apple.quarantine ~/Applications/WoWSilicon.app
# or: /Applications/WoWSilicon.app

API / object names

  • GET /files/download/macos → redirects to the launcher stream
  • GET /files/downloadlauncher/macos → streams ClasslessLauncherMacos.zip
  • GET /files/launchers → per-platform availability
  • Config key: launcherservice.macosLauncherName (default ClasslessLauncherMacos.zip)
  • WoWSilicon Turoran mirror key: mirrors/WoWSilicon.app.zip (presign allowlisted)
