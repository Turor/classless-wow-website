Apple Silicon / macOS

Classless does not yet ship a dedicated macOS launcher zip. Until ClasslessLauncherMacos.zip is published to the object store, use WoWSilicon to run classic clients on Apple Silicon, then point the realmlist at this server.

Recommended: WoWSilicon

WoWSilicon is an open-source macOS launcher for Vanilla 1.12.1, TBC 2.4.3, and WotLK 3.3.5a on Apple Silicon. It bundles a Wine runtime and client patching tools.

  • Project: github.com/WoWSilicon/WoWSilicon
  • Downloads / site: wowsilicon.github.io
  • Requirements: Apple Silicon Mac, recent macOS, a legally acquired local WoW client folder

Classless launcher pipeline (coming soon)

The website and API already expose the same download hooks used for Windows and Linux:

  • GET /files/download/macos → redirects to the launcher stream
  • GET /files/downloadlauncher/macos → streams the zip when published
  • GET /files/launchers → reports per-platform availability
  • Config key: launcherservice.macosLauncherName (default ClasslessLauncherMacos.zip)
